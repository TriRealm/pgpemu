PGP Emulator

Flash your ESP32 directly from this page
This page requires Chrome, Edge, or Opera on desktop. Firefox, Safari, and mobile browsers are not supported (Web Serial isn't available there).

Before you start

  1. Plug your ESP32 into your computer via USB.
  2. Make sure no other program (Arduino IDE, a serial monitor, etc.) has the port open.
  3. Click the button below, then select your device's port when prompted.

Flash firmware

This installs the latest PGP Emulator firmware. Existing settings/secrets are kept unless you choose "Erase device" during install.

Your browser doesn't support Web Serial. Please use Chrome, Edge, or Opera on desktop. Web Serial is not available. Make sure you're using this page over HTTPS.

Device Console

Connect to a device that's already flashed and running to view its log output and send single-character settings commands - the same commands available over a wired UART connection.

Not connected
Waiting to connect...
Available commands
sToggle autospin (all devices)
cToggle autocatch (all devices)
pToggle powerbank ping
iToggle showing autospin/catch on LED
lToggle verbose logging
BToggle input button available
OToggle output LED available
AStart BT advertising
aStop BT advertising
SSave settings permanently
rShow runtime counter
tShow BT connection times
CShow BT client states
TShow FreeRTOS task list
RRestart device
h / ?Help

Note: X (secrets mode) and m (set target connections) need multiple keystrokes in sequence and aren't supported from this simple console - use the secrets uploader page for uploading secrets instead.
